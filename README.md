# Gece hayatı aktivite uygulaması

Geçici ürün adı `src/config/brand.ts` ve `app.json` içindeki `expo.name` alanındadır.

```bash
npm install
npx expo start --web
```

Anahtar yoksa uygulama demo modunda açılır. Supabase için `.env.example` dosyasını `.env` yapın ve `supabase/migrations/001_init.sql` betiğini projeye uygulayın.
